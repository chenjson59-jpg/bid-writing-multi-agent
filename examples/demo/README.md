# 演示数据集（examples/demo）

一套**可公开再分发**的合成招标数据，用于在没有付费 API、没有真实招标文件的机器上
演示「解析 → 抽取 → 编写 → 覆盖报告 → Word 导出」全链路。

## 1. 数据来源与脱敏声明

- 全部内容为**虚构合成**：由 `scripts/make_demo_tender.py` 用代码生成，项目名称、
  招标编号、招标人、金额、人员、业绩、联系方式均为示例值，不对应任何真实项目或单位。
- 未使用任何前公司文件、客户资料、真实人员信息或内部模板；不含真实招标文件原文。
- 可随仓库公开，也可自由修改后重新生成。

## 2. 文件构成

| 路径 | 说明 |
|---|---|
| `tender_demo.pdf` | 合成招标文件，10 页 / 6 章，带一级书签（保证章节可还原） |
| `bidder_profile.demo.json` | 合成投标人资料（公司、资质、业绩、人员、财务、联系人） |
| `artifacts/extraction.json` | 人工整理的抽取结果（5 项评分因素、8 项投标文件格式、33 条资格/技术要点中的关键项） |
| `artifacts/outline.json` | 章节大纲（9 章：3 章生成、5 章填模板、1 章占位） |
| `artifacts/sections/*.md` | 各章预置正文（供组装 `bid.md` 与 `report.json`） |

生成脚本：

| 脚本 | 作用 |
|---|---|
| `scripts/make_demo_tender.py` | 重新生成 `tender_demo.pdf` |
| `scripts/install_demo_data.py` | 解析 PDF、写入抽取结果、组装编写产物，可选写入资料库 |

## 3. 安装演示数据

```powershell
uv run python scripts/make_demo_tender.py      # 可选：重新生成 PDF
uv run python scripts/install_demo_data.py     # 装入 upload/
```

安装后：

- 文档库出现 `tender_demo.pdf`（6 章、已抽取）；
- 「标书历史」出现一条 9 章产物，含 `bid.md` / `bid.docx` / `report.json` / `outline.json`；
  首次打开章节列表时会按 `bid.md` + `outline.json` 反推生成 `sections/`，之后即可按章
  编辑、重写与锁定；
- 若数据库可用，资料库出现「示例水务工程有限公司」，编写页可一键载入。

产物为**程序真实计算**：`report.json` 由 `build_report()` 依据 `artifacts/sections/*.md`
与 `extraction.json` 生成，覆盖率、占位符与正文严格一致，不是手写死数据。

预期指标（安装后即可核对）：

| 指标 | 数值 |
|---|---|
| 章节数 | 9 |
| 总字数（去空白） | 4279 |
| 格式覆盖率 | 8/8（100%） |
| 评分覆盖率 | 4/5（80%） |
| 未覆盖评分因素 | 财务状况 |
| 占位符 | 15 个（去重后） |

## 4. 演示流程（3 分钟固定脚本）

| 时间 | 环节 | 动作 | 要说的一句话 |
|---|---|---|---|
| 0:00–0:20 | 开场 | 展示顶栏 API / 队列 / Worker 三个状态点 | 「三个组件每 5 秒探活，掉线会先在顶栏变色，不会到操作时才报错」 |
| 0:20–1:00 | 上传解析 | 上传 `tender_demo.pdf`，展示解析进度与章节数 | 「本地解析器从 PDF 书签还原 6 章，云端解析失败会自动回退本地」 |
| 1:00–1:50 | 编写 | 文档库选该文档 → 资料库载入「示例水务工程有限公司」→ 参数选 2 章 → 确认成本 | 「资料一次录入多次复用，参数直接约束成本」 |
| 1:50–2:40 | 结果 | 看本次 2 章的覆盖率 / 章节评分 / 占位符 / 未覆盖因素；再到历史页打开预置 9 章产物对照 | 「只写 2 章时格式覆盖 2/8、评分 3/5——参数直接约束成本；完整 9 章预置产物是格式 8/8、评分 4/5，未覆盖的财务状况会被明确列出而不是隐藏」 |
| 2:40–3:00 | 产物 | 打开本次 `bid.docx` → 回「标书历史」 | 「Word 可直接进入人工核对流程，历史产物可回看」 |

## 5. 兜底素材

- **断网 / 无 API Key**：预置产物已在历史页，可完整演示结果页与 Word 导出；
- **Redis / worker 未启动**：`scripts\demo.ps1 -Backend local` 走进程内后端，不需 Redis；
- **任务失败**：准备一张失败任务卡片截图，说明「沿用原参数重试」与错误分级提示；
- **录屏**：提前录一段 2–3 分钟无剪辑视频，现场 API 不可用时直接播放。

## 6. 录屏操作卡

录制兜底视频的操作卡为同目录 `录屏操作卡.md`（仅本地使用，已在 `.gitignore` 中）：录制前检查、
五段分镜与逐字口播、失败兜底、录制后自查，以及真实数据的恢复命令。成片目标 2–3 分钟、无剪辑。
